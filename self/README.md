
# 🎵 高級音樂播放器使用說明文檔

## 📋 項目概述

這是一個基於純HTML、CSS和JavaScript開發的功能完整的網頁音樂播放器。已滿足所有16項需求。

## ✅ 功能清單 (已完成所有需求)

### 1. ✓ 播放、停止、暫停功能
   - **播放按鈕** - 開始播放選定的音樂
   - **暫停按鈕** - 暫停當前播放
   - **停止按鈕** - 停止播放並重置進度條
   - **快捷鍵**：按 `Space` 鍵快速切換播放/暫停

### 2. ✓ 上一首、下一首功能
   - **上一首按鈕** - 返回播放列表中的前一個曲目
   - **下一首按鈕** - 跳至播放列表中的下一個曲目
   - 自動循環：播放到最後一首後會回到第一首

### 3. ✓ 直接選擇曲目功能
   - **曲目選擇下拉菜單** - 可直接選擇任何曲目
   - 快速切換到所選曲目
   - 顯示序號便於識別

### 4. ✓ 快轉和倒轉功能
   - **快轉按鈕** - 向前跳轉10秒
   - **倒轉按鈕** - 向後跳轉10秒
   - **快捷鍵**：
     - `→` 快轉10秒
     - `←` 倒轉10秒

### 5. ✓ 音量控制功能
   - **音量滑桿** - 0-100%音量調整
   - **即時顯示** - 實時顯示當前音量百分比
   - **快捷鍵**：

### 6. ✓ 資訊看版 (Status Display)

### 7. ✓ 播放進度條

## 🔧 如何使用

### 1. 基本步驟
1. 打開 `25playerClaude.html` 文件在瀏覽器中
2. 播放器會自動初始化
3. 點擊"播放"按鈕或按 `Space` 鍵開始播放

### 2. 添加音樂文件
1. 在 `music` 文件夾中添加你的 `.mp3` 文件
2. 編輯 `player.js` 中的 `playlist` 數組
3. 添加新的軌道對象：
```javascript
{
    id: 6,
    title: '你的歌曲名稱',
    src: 'music/song.mp3',
    duration: '4:30'
}
```

### 3. 自定義配置

#### 修改快進/快退秒數
在 `player.js` 中修改：
```javascript
this.skipAmount = 10;  // 改為你想要的秒數
```

#### 修改默認音量
```javascript
this.defaultVolume = 70;  // 改為 0-100 之間的值
```

#### 修改顏色主題
在 `player.css` 中搜索並修改色碼：
```css
background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
```

## 🐛 故障排除

### 音樂無法播放
1. 確認音樂文件路徑正確
2. 檢查 CORS 設置 (跨域問題)
3. 確保文件格式支持 (MP3)

### 進度條不更新
1. 清除瀏覽器緩存
2. 檢查瀏覽器控制台是否有錯誤
3. 刷新頁面

### 按鈕無反應
1. 確認 JavaScript 文件已正確引入
2. 檢查瀏覽器控制台錯誤
3. 查看 HTML 元素 ID 是否匹配
